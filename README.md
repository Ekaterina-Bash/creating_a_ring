# **Создание кольца из фотополимерной смолы**

В данном проекте применяется технология создания трёхмерных объектов путём послойного отверждения жидких фотополимерных смол под воздействием ультрафиолетового света. Она позволяет получать высокодетализированные модели с гладкой поверхностью. 

## 1. Проектирование в Rhino

В программе Rhino создаем модель кольца, учитывая охват пальца. Далее, с помощью технологии SubD, корректируем форму. Сохраняем файл в формате .stl


## 2. Печать фотоплимерной смолой

Ванная заполнена жидкой смолой, платформа постепенно поднимается по ходу того, как излучение воздействует послойно на смолу, в соотвествии с заданной моделью.

## 3. Постобработка

Постобработка проходит в несколько этапов:
1) очистка от неотвержденной смолы с помощью спирта
2) удаление поддержек с помощью кусачек
3) финальное отверждение УФ-излучением в специальной камере для достижения максимальной прочности
4) шлифование
